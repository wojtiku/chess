# What does the learner actually see when the coach answers?

Type: prototype
Status: open
Blocked by: 01

## Question

The research proposes a ladder — question, principle, board clue, candidate comparison, reveal.
Is that the right shape for this learner in this app?

Build the rough thing: a real position from a beginner's game, and the coach panel at each rung,
including what the board shows and what the learner is prevented from seeing. Include the
wording the learner reads. Then put it in front of the developer and watch which rung feels like
teaching and which feels like being told the answer.

Latency is up to 15s, so the prototype must also show what the learner sees while waiting.
